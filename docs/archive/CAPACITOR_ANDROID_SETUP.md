# Capacitor Android Setup — Streambert External Player Plugin

This document explains how to set up the Android project to use the pure-native ExternalPlayer plugin implemented in `android/src/main/java/com/truelockmc/streambert/`.

## Prerequisites

- Node.js 18+
- Android Studio Hedgehog or newer
- Android SDK 34
- Java 17

## Step 1: Initialize Capacitor (if not already)

```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init Streambert --web-dir=dist
npx cap add android
```

## Step 2: Copy Java Plugin Files

The plugin files are already in `android/src/main/java/com/truelockmc/streambert/`:
- `ExternalPlayerPlugin.java`
- `AndroidProxyServer.java`

If `android` folder was generated by Capacitor, copy them to:
```
android/app/src/main/java/com/truelockmc/streambert/
```

## Step 3: Register Plugin in MainActivity

Edit `android/app/src/main/java/com/truelockmc/streambert/MainActivity.java`:

```java
package com.truelockmc.streambert;

import android.os.Bundle;
import com.getcapacitor.BridgeActivity;
import com.getcapacitor.Plugin;
import java.util.ArrayList;

public class MainActivity extends BridgeActivity {
    @Override
    public void onCreate(Bundle savedInstanceState) {
        // Register custom plugin
        registerPlugin(ExternalPlayerPlugin.class);
        super.onCreate(savedInstanceState);
    }
}
```

For Capacitor 5+, you can also use automatic registration via `capacitor.plugins.json`, but explicit registration is safer.

## Step 4: AndroidManifest.xml Permissions & Queries

Edit `android/app/src/main/AndroidManifest.xml`:

```xml
<manifest ...>
    <!-- Required -->
    <uses-permission android:name="android.permission.INTERNET" />
    <!-- For subtitle download to public Downloads (Android 9 and below) -->
    <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" android:maxSdkVersion="28" />
    <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" android:maxSdkVersion="32" />

    <!-- For Android 11+ package visibility: allow querying video players -->
    <queries>
        <intent>
            <action android:name="android.intent.action.VIEW" />
            <data android:mimeType="video/*" />
        </intent>
        <intent>
            <action android:name="android.intent.action.VIEW" />
            <data android:mimeType="video/mp4" />
        </intent>
        <intent>
            <action android:name="android.intent.action.VIEW" />
            <data android:mimeType="application/x-mpegURL" />
        </intent>
        <!-- Known players -->
        <package android:name="org.videolan.vlc" />
        <package android:name="is.xyz.mpv" />
        <package android:name="com.mxtech.videoplayer.ad" />
        <package android:name="com.mxtech.videoplayer.pro" />
        <package android:name="com.brouken.player" />
        <package android:name="dev.anotherwidget.ftp" />
    </queries>

    <application ...>
        <activity ...>
        </activity>
    </application>
</manifest>
```

**Note:** `QUERY_ALL_PACKAGES` is discouraged for Play Store. Use `<queries>` as above.

## Step 5: Build Web Assets

```bash
npm run build
npx cap copy android
```

This copies `dist/` to `android/app/src/main/assets/public`.

## Step 6: Build APK

```bash
cd android
./gradlew assembleDebug
# APK at android/app/build/outputs/apk/debug/app-debug.apk
```

For release:

```bash
./gradlew assembleRelease
# Sign with keystore
```

## Step 7: Test on Physical Device

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb logcat | grep -i "ExternalPlayer\|AndroidProxy"
```

Test cases:
- Install VLC from Play Store
- Open Streambert, search movie, select source, tap external player
- Verify chooser shows VLC, plays

## Plugin API (JS Side)

The plugin is accessed via `androidBridge.js`:

```js
import { getInstalledPlayersNative, launchPlayerNative, startProxyNative } from './androidBridge.js';

// Detection
const players = await getInstalledPlayersNative();
// [{packageName: "org.videolan.vlc", label: "VLC", type: "android", ...}]

// Launch
await launchPlayerNative({
  url: "https://.../video.m3u8",
  packageName: "org.videolan.vlc",
  mimeType: "video/*",
  title: "Movie Title",
  headers: {"User-Agent": "...", "Referer": "..."},
  subtitle: "/sdcard/Download/StreambertSubs/Movie.en.vtt"
});

// Proxy
const {localUrl, port} = await startProxyNative({
  targetUrl: "https://.../playlist.m3u8",
  headers: {"Cookie": "...", "Referer": "..."},
  subtitleUrl: null
});
// localUrl = http://127.0.0.1:port/https/host/path
```

## Fallback: Intent URI (No Plugin)

If Capacitor plugin not available (e.g., pure WebView without native bridge), `androidBridge.js` falls back to Intent URI:

```js
window.location.href = "intent:https://...#Intent;action=android.intent.action.VIEW;type=video/*;package=org.videolan.vlc;S.title=Movie;S.Referer=https://...;end";
```

This requires user gesture (click) and may be blocked if not triggered by user.

## Storage: Subtitles

- Current: `/sdcard/Download/StreambertSubs/` (public Downloads)
- For Android 10+ scoped storage, better to use `context.getExternalFilesDir(null)/StreambertSubs` which doesn't need permission
- Players like VLC scan Downloads automatically, so public path is more compatible
- Alternative: Use `MediaStore` API for Android 10+

## Troubleshooting

- **No players detected:** Check `<queries>` in manifest, ensure VLC installed, check logcat for PackageManager logs
- **Intent not launching:** Check `FLAG_ACTIVITY_NEW_TASK` flag, ensure URL is valid http/https, not `about:blank`
- **Proxy 403:** Host validation failed — ensure targetUrl host matches extracted host from /https/host/path
- **Subtitle not showing:** Check file exists via `adb shell ls /sdcard/Download/StreambertSubs/`, ensure player supports `subtitles_location` extra (VLC does, MX does)
- **Headers not working:** Check if player ignores Referer (MX) — use proxy
